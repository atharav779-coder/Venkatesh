# Venkatesh - SkyVault Aircraft Encyclopedia

An elegant, interactive aircraft encyclopedia featuring detailed 3D flip flashcards and specifications for over 40 aircraft across 8 categories:

- **Commercial Airliners** (Boeing 747-8, Airbus A380, Boeing 787, Airbus A350, Boeing 777X, A320neo, Embraer E195-E2)
- **Fighter Jets** (F-22 Raptor, F-35 Lightning II, Su-57 Felon, Eurofighter Typhoon, Dassault Rafale, F-16, F/A-18E/F Super Hornet, Chengdu J-20)
- **Private & Business Jets** (Gulfstream G700, Bombardier Global 7500, Dassault Falcon 10X, Cessna Citation Longitude)
- **Cargo Aircraft** (Antonov An-225 Mriya, Boeing 747-8F, Airbus BelugaXL, C-5M Super Galaxy)
- **Military Transport** (Boeing C-17 Globemaster, C-130J Hercules, A400M Atlas, Bell Boeing V-22 Osprey)
- **Trainers** (BAE Hawk T.2, Beechcraft T-6 Texan II, Pilatus PC-21, KAI T-50 Golden Eagle)
- **Helicopters** (AH-64E Apache Guardian, UH-60M Black Hawk, Mi-24 Hind, CH-47F Chinook, Airbus H145)
- **Seaplanes & Amphibious** (Canadair CL-415 SuperScooper, ShinMaywa US-2, AVIC AG600 Kunlong, DHC-6 Twin Otter)

## Features
- **Modern Aviation Theme**: Dark cockpit-style theme with animated starfield and glowing accents.
- **Interactive Flashcards**: Click any aircraft card to flip and view 8+ detailed technical specifications and history.
- **Locally Hosted Photos**: High-resolution, optimized images for all aircraft.
- **Responsive Navigation**: Category quick-jump navigation and mobile-friendly drawer menu.

## Quick Start
Open `index.html` in any modern web browser or run:
```bash
python -m http.server 3000
```
and visit `http://localhost:3000`.
