# SkyVault Website Architecture & Features

## Core Features
1. **Interactive 3D Flashcards:**
   - Planes are displayed as interactive cards.
   - Clicking deep-dive buttons ("Granular Cabin", "Airframe History", "Operational Performance") dynamically flips the card 180 degrees via CSS 3D transforms (`rotateY`).
   - The back of the card dynamically renders the selected granular data from a JSON object.
   - Clicking the card again resets and flips it back.

2. **Categorization & Filtering:**
   - Aircraft are categorized into 8 sections: Commercial, Fighter Jets, Private Jets, Cargo, Military Transport, Trainers, Helicopters, and Seaplanes.
   - The UI includes a category navigation bar (`.cat-nav`) to jump between sections smoothly.

3. **Search Functionality:**
   - A real-time search bar filters the displayed aircraft by matching text against plane names and tags.

4. **Dynamic Data Management:**
   - Basic plane info (images, roles, speeds, range) is stored in a JavaScript `const aircraft` object.
   - Granular deep-dive data is stored in a `<script type="application/json" id="detailDataObj">` block to ensure synchronous, crash-free parsing before the main JS initializes.

## Visual Design & Theming
1. **Glassmorphism Aesthetic:**
   - The site uses a shiny marble glassmorphism theme.
   - The background is a soft, warm gradient (`#ffffff -> #f3f4f6 -> #e5e7eb`) mimicking polished marble.
   - Accents are done with an elegant orange-to-magenta gradient (`#f97316` to `#ec4899`).
   - UI elements (Navbar, Cards) use frosted glass effects with `backdrop-filter: blur(16px)` and semi-transparent white backgrounds (`rgba(255, 255, 255, 0.7)`).

2. **Typography:**
   - **Hero Heading:** Uses `Playfair Display` (italic, serif) for a high-end, luxury aesthetic, colored with the orange-magenta gradient.
   - **Headers:** Uses `Montserrat` (bold, geometric, clean).
   - **Body/Stats:** Uses `Outfit` (modern, highly readable sans-serif).

## Technical Architecture
1. **Build System:**
   - Powered by **Vite** for lightning-fast HMR and bundling.
   - Configured via `package.json` (`"type": "module"`) and `vite.config.js`.

2. **Styling Framework:**
   - Uses **TailwindCSS v4**, imported natively via `@import "tailwindcss"` in `style.css` and processed through the official `@tailwindcss/vite` plugin.
   - Custom CSS is heavily used for the 3D card flips (`transform-style: preserve-3d`), scroll reveals (`.reveal`), and glassmorphism styling that goes beyond standard Tailwind utility classes.

3. **Vanilla JavaScript:**
   - No frontend framework (React/Vue) is used. The UI is completely generated by vanilla JS DOM manipulation (`document.createElement`, `innerHTML`, `eventListeners`).
   - Heavy use of event delegation and `e.stopPropagation()` to handle the button clicks inside the flashcards without triggering unintended flips.
